# Настройка перевода текста через Yandex Cloud Vision OCR

## Обзор

В chiaki-ng добавлена функция автоматического перевода текста с экрана игры с английского на русский язык с помощью Yandex Cloud Vision OCR.

## Возможности

- Распознавание текста на экране в режиме реального времени
- Автоматический перевод с английского на русский
- Отображение переведенного текста поверх оригинального с сохранением позиции
- Активация по нажатию горячей клавиши **Alt+T**

## Настройка

### 1. Получение учетных данных Yandex Cloud

#### 1.1. IAM Токен

IAM токен можно получить с помощью команды:

```bash
yc iam create-token
```

**Важно:** IAM токен действителен 12 часов, после чего нужно получить новый.

#### 1.2. ID Каталога

ID каталога можно найти в консоли Yandex Cloud или получить командой:

```bash
yc config list
```

Ищите параметр `folder-id`.

### 2. Настройка в chiaki-ng

1. Откройте chiaki-ng
2. Перейдите в **Настройки** (Settings)
3. Откройте вкладку **Конфигурация**
4. Найдите секцию **"Настройки перевода Yandex Cloud (для Alt+T)"**
5. Введите:
   - **IAM Токен** в поле "IAM Токен"
   - **ID Каталога** в поле "ID Каталога"
6. Сохраните настройки

## Использование

### Во время игры:

1. Нажмите **Alt+T** для захвата текущего кадра и распознавания текста
2. Подождите несколько секунд (обычно 2-5 секунд)
3. Переведенный текст появится поверх оригинального текста
4. Нажмите **Alt+T** снова для переключения видимости оверлея или для нового распознавания

### Индикатор активности

Когда перевод активен, в правом нижнем углу экрана появляется зеленый индикатор:
```
┌─────────────────────┐
│ Translation Active  │
│ Alt+T to toggle     │
└─────────────────────┘
```

## Технические детали

### Архитектура

- **YandexOCR** - модуль для работы с Yandex Cloud Vision OCR API
  - Распознавание текста на изображении
  - Автоматический перевод через Yandex Translate API
  
- **TextOverlay** - компонент для отображения переведенного текста
  - Масштабирование координат под размер окна
  - Полупрозрачный фон для читаемости
  - Автоматический подбор размера шрифта

- **QmlMainWindow** - интеграция в главное окно
  - Захват текущего видео фрейма
  - Обработка горячей клавиши Alt+T
  - Управление оверлеем

### Файлы

**Заголовочные файлы:**
- `gui/include/yandexocr.h` - API для Yandex Cloud Vision OCR
- `gui/include/textoverlay.h` - Компонент оверлея
- `gui/include/settings.h` - Методы для хранения учетных данных
- `gui/include/qmlsettings.h` - QML свойства для настроек

**Исходные файлы:**
- `gui/src/yandexocr.cpp` - Реализация работы с Yandex Cloud API
- `gui/src/textoverlay.cpp` - Реализация текстового оверлея
- `gui/src/qmlmainwindow.cpp` - Интеграция в главное окно
- `gui/src/qmlsettings.cpp` - Реализация QML свойств

**QML:**
- `gui/src/qml/SettingsDialog.qml` - UI для настроек
- `gui/src/qml/TranslationOverlay.qml` - QML компонент оверлея

## Ограничения

- Распознается только английский текст
- Перевод только на русский язык
- IAM токен действителен 12 часов
- Требуется активный аккаунт Yandex Cloud
- Работает только во время активной игровой сессии

## Устранение неполадок

### Перевод не работает

1. **Проверьте учетные данные:**
   - IAM токен не истек (обновляется каждые 12 часов)
   - ID каталога указан корректно

2. **Проверьте логи:**
   - Включите подробное логирование в настройках
   - Проверьте логи на наличие ошибок от Yandex Cloud API

3. **Проверьте платежный аккаунт Yandex Cloud:**
   - Аккаунт должен быть в статусе ACTIVE или TRIAL_ACTIVE
   - Должны быть доступны квоты для Vision OCR

### Текст не распознается

1. Убедитесь, что на экране есть четкий английский текст
2. Попробуйте захватить кадр с более контрастным текстом
3. Размер текста должен быть достаточно крупным

### Оверлей не отображается

1. Проверьте, что распознавание завершилось успешно (смотрите логи)
2. Убедитесь, что на изображении был найден текст
3. Попробуйте нажать Alt+T для переключения видимости

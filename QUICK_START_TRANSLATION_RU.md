# Быстрый старт: Перевод текста в chiaki-ng

## Что это?

Новая функция позволяет переводить английский текст на экране игры на русский язык одним нажатием клавиши!

## Быстрая настройка (5 минут)

### Шаг 1: Получите учетные данные Yandex Cloud

Если у вас уже установлен Yandex Cloud CLI:

```bash
# Получить IAM токен (действует 12 часов)
yc iam create-token

# Получить ID каталога
yc config get folder-id
```

**Не установлен CLI?** Следуйте инструкции: https://yandex.cloud/ru/docs/cli/quickstart

### Шаг 2: Настройте chiaki-ng

1. Откройте **Настройки** → вкладка **Конфигурация**
2. Прокрутите вниз до секции **"Настройки перевода Yandex Cloud"**
3. Вставьте:
   - IAM Токен
   - ID Каталога
4. Готово!

### Шаг 3: Используйте во время игры

1. Запустите игру через chiaki-ng
2. Когда увидите английский текст, нажмите **Alt+T**
3. Подождите 2-5 секунд
4. Переведенный текст появится на экране!

## Пример использования

```
До нажатия Alt+T:
┌──────────────────────────┐
│  PRESS START TO BEGIN    │
└──────────────────────────┘

После нажатия Alt+T:
┌──────────────────────────┐
│ НАЖМИТЕ START ДЛЯ НАЧАЛА │  ← Переведенный текст
└──────────────────────────┘
```

## Полезные советы

✅ **Работает с:**
- Текстом в меню игры
- Субтитрами
- Подсказками на экране

❌ **Не работает с:**
- Текстом, который быстро исчезает
- Очень мелким текстом
- Рукописным текстом

## Частые вопросы

**Q: Токен перестал работать**
A: IAM токен действует 12 часов. Получите новый командой `yc iam create-token`

**Q: Перевод медленный**
A: Это нормально - распознавание и перевод занимают 2-5 секунд

**Q: Текст не распознается**
A: Убедитесь, что текст четкий, контрастный и достаточно крупный

**Q: Это бесплатно?**
A: Yandex Cloud предоставляет бесплатный уровень (free tier). Проверьте тарифы: https://yandex.cloud/ru/docs/vision/pricing
